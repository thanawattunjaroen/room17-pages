# TANCHAROEN PLACE

Static browser application for managing monthly rooms, meters, invoices, receipts, income, expenses, and PDF reports.

The application stores data only in the current browser. It starts empty. Use Settings to import a JSON backup or export a backup before clearing browser data or moving devices.

This repository contains only the public website. Tenant records, private repository history, signatures, personal receipt defaults, backups, and sample documents are excluded. Enter receipt details and upload a signature in Settings; these stay in your browser and exported backups.

GitHub Pages publishes the `main` branch root. An owner can update this site by building and publishing a new sanitized package from the private source project.
